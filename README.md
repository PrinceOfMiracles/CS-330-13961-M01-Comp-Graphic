**CS 330 Computational Graphics and Visualization Portfolio**

This repository contains my final project artifacts for CS 330: Computational Graphics and Visualization. For this project, I created a 3D electronics workstation scene using OpenGL and C++. The scene includes a blue ESD mat, black toolbox, wristwatch, and .50-cal-style bullet bottle opener. The project demonstrates my ability to model low-polygon 3D objects, apply textures and lighting, and create an interactive camera-controlled 3D scene.

**Reflection**

**How do I approach designing software?**

I approach designing software by first identifying the requirements and then breaking the project into smaller parts that are easier to complete. For this project, I started with the reference image and narrowed the scene to four objects that could be modeled with basic OpenGL shapes. This helped me plan the scene before writing too much code. I used boxes, cylinders, a cone, a tapered cylinder, a plane, and a torus to create the main objects while keeping the scene realistic for the project timeline.

This project helped me improve my design skills by making me think about how real-world objects can be simplified into basic shapes. I also learned how important placement, scale, color, and lighting are when trying to make a 3D scene recognizable. In future projects, I can use this same design approach by breaking a larger problem into smaller pieces, planning the structure first, and then improving the details through iteration.

---

**How do I approach developing programs?**

I approach developing programs by building the main functionality first and then improving it through testing and feedback. During this project, I worked through the milestones gradually by adding objects, camera movement, textures, lighting, and final polish. Iteration was important because the scene changed several times based on what worked visually and what needed improvement. For example, I adjusted the lighting after the scene appeared too dark and made changes to the object colors and textures so the final scene was easier to view.

My development approach also became more organized throughout the project. Instead of putting everything into one section of code, I used helper functions such as `RenderESDMat()`, `RenderToolbox()`, and `RenderBulletOpener()` to keep the object code easier to read and maintain. This helped me see how modular code can make a larger project easier to update and debug.
